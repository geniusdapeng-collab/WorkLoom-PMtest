本机实际 PM 入口在首笔窗口验证发送了 4,174 输入 tokens 和 `max_tokens=393216`。供应商返回相同输入计量、2,942 输出、总计 7,116、`finish_reason=stop`，SHA-256 `a53e4b3cce8916a3319981b830dafff6bfa57bef3544376327ca6185cdad4262`。预测 8,270，真实结算 7,116。另用非收费夹具证明：真硬额度为 300,000 时，原样请求在出站前拒绝；预测阈值不会冒充模型窗口。[B]

自动岗位选择按同一实测库核验原14条、预先冻结的28条目标和另一轮独立设计的14条，共56/56，旧版首批14条为8/14。模式路由单独统计，`ask/agent/quest/clarify` 各2条，8/8 均由真实模型决策。工具链实测一次由模型发起官方 Search，实际工具调用1次、无工具错误、2次模型响应，返回可核对来源。岗位命中率与材料内容质量分别计分。[B/C]

初版28份盲测均生成结构有效的文件；冻结判据不进入被测模型。语义样本保留原失败、每次修正及最终回执。两个四角色长目标分别产出需求、代码、代码测试、评测和交付说明；原始模型自写测试与事前独立业务断言分别运行，不以文件存在替代测试。最终各轮语义判分和精确源码验收回执见任务交付报告。[B/C]

该审计没有改变数据库迁移或新增 HTTP 字段、也没有开放生产外发。客户生产负载、签名安装包、完整 RDAS 276 项、真实用户研究与账单对账未以本次合成测试替代。回退使用该变更的普通 Git revert；保留所有原始业务评测和计量回执。[A/D]
